## Ways to use models here

Start with the first and go further only for a reason.

1. **Stay in this session.** Work on the model you are running. Right for small, reversible changes and for work that already has its context here.
2. **A subagent of your own harness.** The `Agent` tool takes `model` (`sonnet`, `opus`, `haiku`, `fable`) and `effort` (`low` to `max`). It starts only Claude models. Right for wide reads, independent work that can run in parallel, and keeping this session's context small.
3. **An Orca worker on another agent.** `grok` for code and reading (start it with `--agent grok` alone), `claude` with `--model opus --effort xhigh` for judgment and the hardest changes, `codex` when a second model family is wanted. Right when another agent's model fits the work better than yours. Read [references/orca.md](references/orca.md) first; it has the commands and what a worker cannot do.
4. **Several models together** (the `swarm`, `arena`, `interrogate`, and `reflect` skills). You asked for this only for risky or contested work. Right for judgment that could split, changes that are costly to undo, and large independent batches.
