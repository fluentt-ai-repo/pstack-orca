## Ways to use models here

Start with the first and go further only for a reason.

1. **Stay in this session.** Work on the model you are running. Right for small, reversible changes and for work that already has its context here.
2. **A subagent of your own harness.** In Claude Code, the `Agent` tool takes `model` (`sonnet`, `opus`, `haiku`, `fable`). Right for wide reads, independent work that can run in parallel, and keeping this session's context small.
3. **An Orca worker on another agent.** The user allowed it. `grok` suits code and reading, but runs the `[models] default` in `~/.grok/config.toml` (`grok-4.7` now), not the preferred `grok-4.7-build-fast`. For that model run `grok -p -m grok-4.7-build-fast --reasoning-effort xhigh` directly. `codex` is available where the work fits it. Read the Orca workers reference in `../resolve-capability/SKILL.md`. Right when another agent's model fits the work better than yours.
4. **Several models together** (the `swarm`, `arena`, `interrogate`, and `reflect` skills). Only for risky or contested work, as the user said. Right for judgment that could split and changes that are costly to undo.

- Remaining usage cannot be read here. If a start fails on a limit, run that seat on another agent for this run, say so in the reply, and change nothing in this skill.
- Say in the reply which model you chose and why, in one line.

## When a task does not match this skill

Decide which kind of mismatch it is.

- **A stable fact is wrong** (a flag a product refuses, a model that is gone). Ask the user. On yes, fix `inventory.md` and append a line to `log.md` with the date, the product version, and what changed. A wrong mechanism in the adapter is not fixed here: tell the user, because pstack ships the adapter.
- **A preference no longer fits.** Ask the user. On yes, edit the sentence under `## Preferences` or add a branch to it, and append a line to `log.md`.
- **A transient state** (a limit, no network). Substitute for this run, say so in the reply, and change nothing.

Edit only files in this directory, and only after the user agrees.
